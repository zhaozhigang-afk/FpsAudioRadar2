# FPS 听障辅助音频雷达

给听障玩家的 FPS 游戏声音方向辅助工具。实时捕获系统输出音频，分析声道方向，用**透明悬浮雷达**显示声音来源方向和类型。窗口无黑色背景，只显示雷达线条和光点，完全不挡游戏画面。

## 功能

- **透明悬浮窗**：无黑色背景，只看到雷达圆环、网格、十字线和声音光点
- **纯雷达界面**：无扫描针，干净不抢眼
- **屏幕居中**：雷达圆心严格对齐屏幕正中心
- **点击穿透**：默认开启，鼠标直接穿过窗口操作游戏，不影响 FPS
- **系统托盘控制**：所有操作通过右下角托盘图标完成
- **三种雷达形状**：圆形雷达（默认）/ 半圆形雷达 / 水平方向条，托盘一键切换
- **多声道 360° 定位**：自动检测立体声 / 四声道 / 5.1 / 7.1 环绕，多声道模式下利用全部声道能量做全圆方位判断
- **增强方向算法**：立体声模式下融合能量差 + 互相关ITD（时间差）+ 多频段加权，方向更精准
- **方向平滑滤波**：指数平滑减少光点抖动
- **音频设备选择**：设置对话框内可选择捕获哪个音频设备
- **状态显示**：雷达底部显示当前设备名、声道数、采样率、是否回环
- **方向增益可调**：托盘菜单直接切换 0.8~2.0
- **中心点大小可调**：托盘菜单直接切换 1~8px
- **三档一键预设**：低/中/高，设置对话框内一键应用
- **自适应噪声门**：根据环境噪声自动调整阈值
- **声音分类**：脚步（蓝）、枪响（红）、爆炸（橙）、开门（紫）、其他（灰）
- **光点语义**：颜色 = 声音类型，越靠近中心 = 声音越近，方位 = 声音方向
- **纯音频捕获**：不读游戏内存、不注入、不模拟键鼠，属于无障碍辅助

## 运行方式

### Python 运行（推荐）

1. 安装 [Python 3.9+](https://www.python.org/downloads/)，安装时勾选 **Add Python to PATH**
2. 安装依赖：`pip install -r requirements.txt`
3. 运行：`python fps_audio_radar.py`

### 自行打包 EXE

双击 `build_exe.bat` 自行打包，完成后 exe 在 `dist\FPS_Audio_Radar.exe`。

## 声道支持说明

| 声道配置 | 定位能力 | 说明 |
|---------|---------|------|
| **立体声 (2ch)** | 前方左右（半圆） | 能量差 + ITD + 多频段融合，只能判断左右，无法区分前后 |
| **四声道 (4ch)** | 360° 全圆 | FL/FR/BL/BR 四声道能量加权向量和，可判断前后左右 |
| **5.1 (6ch)** | 360° 全圆 | 增加中置和环绕声道，方位更精细 |
| **7.1 (8ch)** | 360° 全圆（最佳） | 8声道全向覆盖，前后左右定位最精准 |

程序启动时自动检测实际声道数，≥4 声道自动进入 360° 全圆定位模式。

> **重要**：Windows 声音设置里需要把播放设备配置为对应的声道数（四声道/5.1/7.1），游戏也要输出对应声道，程序才能拿到多声道数据。如果系统设为立体声，即使设备支持 7.1 也只能拿到 2 声道。

## 雷达形状

| 形状 | 说明 |
|------|------|
| **圆形雷达**（默认） | 全圆，多声道模式下光点可出现在 360° 任意方位；立体声模式下光点在上半圆 |
| **半圆形雷达** | 只显示上半圆，适合纯立体声（只能检测前方左右） |
| **水平方向条** | 最简洁，一条横条，光点左右移动表示方向 |

## 设置对话框

托盘 → 设置，可调整：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 音频设备 | 自动 | 列表 | 选择捕获哪个设备的回环/输入 |
| 雷达形状 | 圆形 | 三种 | 圆形 / 半圆形 / 水平方向条 |
| 灵敏度 | 1.3 | 0.5~2.5 | 越大越容易捕捉微弱声音 |
| 信噪比阈值 | 1.8 | 1.0~5.0 | 信号比噪声强多少倍才触发光点 |
| 方向增益 | 1.0 | 1.0~3.0 | 左右方向感的放大程度 |
| 噪声门下限 | 0.008 | 0.001~0.05 | 自适应底噪的最低值 |
| 光点存活(秒) | 1.4 | 0.5~3.0 | 光点从出现到淡出的时间 |
| 光点大小 | 1.0 | 0.5~4.0 | 声音光点的整体大小倍率 |

### 三档一键预设

| 预设 | 适用场景 |
|------|---------|
| **低** | 安静环境，防误触发 |
| **中**（默认） | 通用平衡 |
| **高** | 嘈杂环境，捕捉远处微弱脚步声 |

## 原理

### 方向判断

**立体声模式**（2声道）：
1. **能量差**：左右声道 RMS 能量差，高频段最可靠
2. **互相关 ITD**：计算左右声道的时间差（耳间时间差），低频段最可靠
3. **多频段融合**：低/中/高三段分别计算方向，按频段特性加权
4. **指数平滑**：减少方向抖动

**多声道模式**（≥4声道）：
- 每个声道对应固定方位角（7.1: FL=315°, FR=45°, C=0°, SL=270°, SR=90°, BL=225°, BR=135°，0°=正前，顺时针）
- 用各声道能量做加权向量和，向量和的角度即声音方位
- 向量模长/总能量 = 方向集中度，集中度越高光点越亮
- LFE 低音炮声道无方向，跳过不计

### 其他
- **声音类型**：基于频谱特征 + 瞬态检测的分类
- **自适应噪声门**：持续学习环境底噪，用信噪比（SNR）判断声音事件
- **延迟**：约 40~80ms
- **音频捕获**：基于 pyaudiowpatch 的 WASAPI loopback
- **透明背景**：基于 PyQt5 的 `WA_TranslucentBackground`

## 使用建议

1. **想获得 360° 定位**：Windows 声音设置 → 播放设备 → 配置 → 选择 7.1（或 5.1/四声道），游戏内音频输出也设为对应声道。雷达用圆形。
2. **只有立体声**：用半圆形雷达即可，光点只在上半圆（前方左右）。
3. **游戏里不要开**「耳机虚拟化」「3D 音效」，保持原生多声道输出，方向最准。
4. 确认 Windows 默认输出设备是游戏实际使用的设备。
5. 雷达默认在屏幕正中央，如果挡准星，托盘关掉点击穿透后拖到角落，再重新开启穿透。
6. 觉得太灵敏容易误触发，用「低」预设或调小灵敏度。
7. 觉得远处脚步抓不到，用「高」预设或调大灵敏度。
8. 切换音频设备后，点「重启音频捕获」或在设置里应用后自动重启。

## 手动选择音频设备

托盘 → 设置… → 「音频设备」下拉框，可手动指定捕获哪个设备：

- **自动选择（默认回环）**：自动捕获 Windows 默认播放设备的回环，推荐大多数情况使用
- **指定设备**：下拉列表会列出所有 ≥2 声道的输入/回环设备，选中后点「应用」，程序自动重启音频捕获

> 注意：必须选择**回环设备**（名称带 `[Loopback]`）才能录到系统输出的游戏声音。普通输入设备（如麦克风）录不到游戏声。

## VB-Cable 虚拟声卡（推荐）

如果你的真实音频设备只有立体声（如普通耳机、HDMI 显示器音箱），但想要获得 **7.1 多声道 360° 定位**，可以使用 VB-Cable 虚拟声卡：

### 什么是 VB-Cable

VB-Cable 是一个免费的虚拟音频设备，安装后会在系统中生成一对虚拟输入/输出设备。游戏声音输出到虚拟线缆，雷达捕获虚拟线缆的回环（支持 8 声道 7.1），同时虚拟线缆再把声音转发到你的真实耳机。

### 下载安装

- **官网**：https://vb-audio.com/Cable/
- 下载 `VB-CABLE`（免费版，单线缆）或 `VB-CABLE A+B`（ donationware，多线缆）
- 解压后以**管理员身份**运行 `VBCABLE_Setup_x64.exe`（64位系统）
- 安装完成后重启电脑

### 配置步骤

1. **Windows 声音设置** → 播放设备 → 找到 `CABLE Input` → 右键「设为默认设备」
2. 右键 `CABLE Input` → 「配置扬声器」→ 选择 **7.1 环绕** → 下一步完成
3. 右键 `CABLE Input` → 属性 → 高级 → 默认格式选 `16位, 48000 Hz`
4. 打开 `CABLE Output` 的属性 → 「侦听」选项卡 → 勾选「侦听此设备」→ 下拉选择你的真实耳机/音箱 → 应用
5. **游戏内音频设置**：输出设备选 `CABLE Input`，声道选 `7.1`（或游戏支持的最高声道）
6. 运行雷达，托盘 → 设置 → 音频设备确认是 `CABLE Input [Loopback]`（或自动选择即可）

### 注意事项

- 侦听功能会有少量延迟（约 10~30ms），对游戏影响不大
- 如果觉得虚拟声卡麻烦，真实设备本身支持多声道（如 USB 多声道耳机），直接用真实设备即可
- 卸载：以管理员身份运行安装程序，点「Remove Driver」

## 音频诊断

项目附带 `audio_diag.py` 诊断脚本，可检测：
- 主机 API 列表
- 默认输出设备名称、声道数、采样率
- 全部音频设备列表
- WASAPI 回环打开测试

运行：`python audio_diag.py`

## 关于反作弊

本程序只读取系统音频输出（和录屏软件录声音同一个原理），**不接触游戏进程、不读内存、不发送输入**。绝大多数反作弊不会判定为外挂。但每个游戏规则不同，使用前自行确认游戏条款。这是无障碍辅助工具。
