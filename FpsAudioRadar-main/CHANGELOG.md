# 更新日志

## [2.0.0] - 2026-09-07

### 新增

- **多声道 360° 定位**：自动检测立体声 / 四声道 / 5.1 / 7.1 环绕，≥4 声道时利用全部声道能量做加权向量和，实现全圆方位判断，不再局限于左右
- **光点大小调节**：设置对话框新增「光点大小」参数（0.5~4.0 倍，默认 1.0），实时生效
- **音频设备选择**：设置对话框新增设备下拉列表，可手动指定捕获哪个音频设备的回环/输入
- **重启音频捕获**：托盘菜单新增一键重启音频，切换设备或异常时使用
- **音频诊断脚本**：新增 `audio_diag.py`，可检测主机 API、默认设备声道数/采样率、全部设备列表、WASAPI 回环连通性

### 优化

- **立体声方向算法全面增强**：从单一左右能量差升级为三路融合
  - 能量差（高频段可靠）
  - 互相关 ITD 耳间时间差（低频段可靠，搜索 ±40 样本）
  - 低/中/高三频段分别计算方向后加权融合
  - 指数平滑减少光点抖动，首次直接赋值避免初始化偏差
- **默认雷达形态改为圆形**：配合 360° 多声道定位，全圆展示更合理
- **音频捕获兼容性修复**：原代码 `as_loopback=True` 参数在 pyaudiowpatch 0.2.12.8 不支持，导致首选策略必败；新增 `get_default_wasapi_loopback()` 标准 API 作为首选，保留 4 层回退
- **事件合并逻辑优化**：多声道模式下按角度差（30°内）合并，立体声按方向差合并
- **方向集中度影响亮度**：多声道模式下，声音方向越集中（向量模长/总能量越高），光点越亮

### 修复

- **声道角度映射错误**：原代码中 SL（左环绕）、SR（右环绕）、C（中置）的方位角定义错误，已修正为标准布局
  - FL=315°, FR=45°, C=0°, SL=270°, SR=90°, BL=225°, BR=135°（0°=正前，顺时针）
- **LFE 低音炮声道误参与定位**：已跳过无方向的 LFE 声道

### 界面

- **去除雷达内所有文字**：删除圆形雷达的「前/后/左/右」方位标注和底部音频状态条，雷达只保留圆环、网格、十字线和声音光点，纯干净
- 音频状态信息仍在控制台（命令行窗口）打印，不影响雷达画面

### 验证

- 多声道 360° 定位通过 9/9 项单元测试（单声道 + 组合验证，角度偏差 0°）
- Python 语法检查通过

## [1.0.0] - 初始版本

- 透明悬浮雷达，WASAPI 系统音频回环捕获

- 三种雷达形状：圆形 / 半圆形 / 水平方向条
